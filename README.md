# Геомұра

Статический сайт с картой Казахстана и интерфейсом на казахском. Основной источник данных — `locations.json`. Никакой сборки, базы данных или API-ключей не требуется. Карта использует Leaflet и OpenStreetMap; для карты и веб-шрифта нужен интернет.

## Локальный запуск

Распакуйте ZIP целиком и запустите `start-site.cmd` (Windows, нужен Python 3). Откроется браузер с адресом localhost. Окно сервера оставьте открытым; Ctrl+C останавливает сервер. Файл `start-site.py` также можно запустить командой `python start-site.py`.

Из этой папки выполните `python -m http.server 8000`, затем откройте http://localhost:8000. Не открывайте index.html двойным щелчком: браузер может блокировать чтение JSON через file://.

### Если карта показывает 403 Access blocked

Это отказ сервера тайлов OpenStreetMap, а не требование Google API. Одно изображение ошибки не раскрывает точную причину блокировки. Открывайте сайт через HTTP/HTTPS, а не file://. Сайт задаёт `strict-origin-when-cross-origin` для передачи источника запросов согласно правилам OSM. Это не снимает блокировки по другим причинам. Если ошибка сохраняется на опубликованном сайте, проверьте конкретный ответ сервера и отправляемый Referer в Network браузера. Информация поставщика: https://wiki.openstreetmap.org/wiki/Blocked_tiles.

## Добавление объектов

Можно редактировать `locations.json` напрямую. Каждый объект содержит:

```json
{
  "id": "unique-object-id",
  "name": "Нысан атауы",
  "category": "canyon",
  "icon": "◈",
  "region": "Облыс немесе аудан",
  "description": "Нысанның сипаттамасы",
  "lat": 43.35,
  "lng": 79.08,
  "demo": false
}
```

Это пример структуры, не проверенные сведения о реальном объекте. `id` должен быть уникальным. Категории: `canyon`, `mountain`, `cave`, `outcrop`, `lake`, `waterfall`, `other`. Значки: `◈`, `▲`, `◎`, `◇`, `◆`. Координаты — числа в десятичных градусах, сначала широта `lat`, затем долгота `lng`. Дробный разделитель — точка. Остальные текстовые поля обязательны. Файл содержит массив объектов: `[ {...}, {...} ]`.

Сайт работает только как дашборд: карта, карточки, поиск и фильтры. Добавление, изменение и удаление объектов выполняются в `locations.json` в репозитории. После сохранения и публикации обновлённого файла сайт покажет новый набор. Локальные черновики в браузере не используются.

В комплекте 20 объектов из двух предоставленных документов, охватывающих 13 областей. Отбор учитывает геологическое разнообразие, узнаваемость и возможность привязки к карте. Дубли объединены, Аккурум в России исключён. Координаты сопоставлены с внешними источниками. Для крупных территорий указаны репрезентативные точки: они не обозначают точные границы или отдельные обнажения. Пояснения доступны в карточках.

Необязательные поля: `coordinateNote` — пояснение к координатам; `sources` — массив объектов с `title` и HTTPS-ссылкой `url`; `documentReference` — отсылка к исходному документу для редактора данных (на сайте не выводится). После изменения JSON перезагрузите страницу.

## Render

Поместите содержимое этой папки в корень GitHub-репозитория. В Render создайте **Static Site**, подключите репозиторий, задайте Build Command: `echo Static-site-ready`, Publish Directory: `.`. Также приложен `render.yaml` для создания через Blueprint. Если файлы лежат в подпапке, укажите её как Root Directory или перенесите содержимое в корень.

## GitHub Pages

В репозитории откройте Settings → Pages, выберите публикацию из ветки `main`, папку `/ (root)` и сохраните. Все пути относительные, поэтому сайт работает и по адресу проекта вида `username.github.io/repository/`.

Не удаляйте подпись OpenStreetMap на карте. Для публичного проекта с большой посещаемостью проверьте правила поставщика тайлов: https://operations.osmfoundation.org/policies/tiles/.

## Фотографии

В `images/<id>/` размещены 129 фотографий, сопоставленных с 20 объектами по подписям предоставленного чата. Сам чат и личная переписка не входят в сайт. Фотографии сохранены без изменения. В карточке работает карусель: кнопки, стрелки клавиатуры при фокусе внутри галереи и горизонтальное касание на телефоне.

В `locations.json` поле `images` содержит массив объектов: `{"src":"images/aktolagay/01.jpg","alt":"Ақтолағай — 1-сурет"}`. Порядок массива задаёт порядок фотографий. Допустимы локальные JPG, JPEG, PNG и WebP в папке объекта. Если массива нет или он пуст, карточка отображается без галереи.

Қапамсай шатқалы Шилі импакт құрылымының орнына қосылды. Мәліметтері берілген Qapamsai_shatqaly_tolyq_malimet.docx құжатынан, 6 фотосуреті жаңа архивтен алынды. Координат бағдарлық деп белгіленген.

## Қазақстан шекарасы

Картада Қазақстанның сұлбасы ақ жиекті қою жасыл сызықпен көрсетіледі. Дерек: Natural Earth, 1:50m, public domain; https://www.naturalearthdata.com/. Геометрия `data/kazakhstan.geojson` файлында сақталады, жариялағанда осы папканы да қосыңыз. Бұл жалпы шолу картасына арналған жалпыланған сұлба; кадастрлық дәлдікке арналмаған. Шекара қабаты маркерлердің астында орналасады және карта әрекеттеріне кедергі келтірмейді.
